Carregando o modelo...

O fator de escala vale para a página e para o AR pelo navegador (WebXR). O Google Scene Viewer sempre abre em 1:1; nele, e em qualquer modo, use a pinça se a opção acima estiver ligada.

Como alinhar o modelo na obra

  1. Fique em frente ao QDC e toque em “Ver em realidade aumentada”.
  2. Aponte para o piso embaixo do QDC e mova o celular devagar até aparecer o círculo de posicionamento.
  3. Toque no ponto do piso que corresponde ao 0,0,0 do projeto. Os eixos do marcador (vermelho = X, verde = vertical, azul = Z) ficam exatamente nesse ponto.
  4. Gire com dois dedos até as paredes do modelo coincidirem com as reais. Arraste para ajustar a posição.

O QR Code só abre esta página: o AR não reconhece o QR para se alinhar sozinho. O alinhamento é o toque no piso mais a rotação feita à mão.

Calibrar escala e origem pela caixa de tomada 4x2

Escolha na lista o objeto que é a caixa 4x2. A página mede esse objeto no arquivo original do projeto escolhido (modelo.glb), calcula o fator para ele ter o tamanho real e gera a versão -real.glb desse projeto.

Selecione o objeto na lista.

“Alinhar pela origem” acrescenta pontos invisíveis no arquivo para o centro da base do modelo coincidir com o 0,0,0. Sem isso, o AR centraliza o modelo pela caixa que o envolve e o 0,0,0 fica fora do ponto tocado. Use “Sem calibrar” se o modelo já está em metros reais. Depois de baixar, coloque o arquivo -real.glb na mesma pasta do index.html no GitHub: a página passa a usá-lo automaticamente, inclusive no Scene Viewer do Android. A prévia funciona na página e no AR via WebXR/iPhone, mas não no Scene Viewer.

Gerar um QR Code para cada projeto

Depois de publicar esta pasta no GitHub Pages, cole aqui o endereço do site. Cada projeto da lista ganha o seu QR Code, que abre direto naquele projeto.

O nome do projeto vem escrito embaixo de cada QR Code no PNG, para você identificar na impressão. Os projetos vêm do arquivo projetos.json.
